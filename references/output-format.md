# Profile output format

**Abbreviations:** TRP3 = Total RP 3; OOC = out of character.

Use this structure. Short fields go in tables. Long paste-ready text goes in `text` code blocks, so TRP3's `{tags}` survive and each block can be copied in one go. Leave out empty optional rows instead of writing "N/A".

````markdown
# <Full name> — TRP3 profile
*WoW: Forever · <Faction> · <Race> <Class>*
*In-game name: <First> (<n>) <Last> (<n>)*

> **Lore notes:** <only if something was changed or flagged: what, why, how to revert>
> **Assumed / invented:** <details you made up; the player can change them freely>

## Paste order in TRP3
1. **Characteristics tab:** the table below, then the Additional information rows, then drag the trait sliders.
2. **About tab:** choose template 3, then paste the blocks into Physical description, Personality and History.
3. **Miscellaneous tab:** fill the At first glance slots, then set Roleplay style yourself.
4. **Toolbar or dashboard:** set Currently and OOC.
````

## Companion profile

A hunter's pet or a warlock's minion gets its own file, in this layout. Leave out an optional row rather than writing "N/A", but always give the in-game pet name. The companion's voice goes in the Companion section of the owner's voice guide, not here.

````markdown
# <Name> — TRP3 companion profile
*Companion of <owner> · <imp, wolf…>*

> **Lore notes:** <only if something was changed or flagged>
> **Assumed / invented:** <details you made up>
````
